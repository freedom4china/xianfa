# 中华民主共和国宪法草案

> 如果未来的中国需要重新定义权力、自由与秩序，那就让我们从今天开始，认真地把这些问题说清楚。

[在线阅读](https://freedom4china.github.io/xianfa/) · [提出建议](https://github.com/freedom4china/xianfa/issues) · [参与讨论](https://github.com/freedom4china/xianfa/discussions) · [贡献指南](CONTRIBUTING.md)

## 这是一个什么项目？

这是一份面向未来的公开协作宪法草案，目的不是给出一个“最终答案”，而是在未来可能建立中华民主共和国时，提前讨论并设计一套能够保障自由、权利、法治与权力制约的制度框架。

它是开放、可修改、可讨论的文本，不是某个组织的正式宪法，也不是“唯一标准答案”。欢迎任何人阅读、质疑、补充和重写。

## 我们的目标

- 约束权力
- 保障权利
- 让制度更清楚、更可解释
- 让不同意见能够被表达和回应
- 把讨论从口号落到条文和制度设计

## 你可以怎么参与？

### 1. 提出问题或建议

在 [Issues](https://github.com/freedom4china/xianfa/issues) 中提出你看到的不足、漏洞或更合理的方案。不要担心格式，关键是说清楚：哪里不合理？为什么？你有什么替代想法？

### 2. 参与讨论

前往 [Discussions](https://github.com/freedom4china/xianfa/discussions) 交流理由、案例和担忧。更重视论证而不是口号，欢迎对比不同制度方案。

### 3. 提交修改

如果你已经有具体修改方案，可以直接提交 Pull Request（PR）。请说明：改了什么、为什么这么改、会如何影响条文逻辑和权利边界。

### 4. 帮忙传播

把项目分享给更多愿意认真讨论公共事务的人，帮助他们阅读、质疑和改进这份草案。

## 协作原则

- 先说明问题，再回应观点
- 以事实、理由和案例为基础
- 容许不同意见，但要求清楚表达
- 把讨论落实到条文和修改中
- 保持透明和持续改进

具体流程请见 [贡献指南](CONTRIBUTING.md)。重大提案的讨论和审查机制请见 [治理规则](GOVERNANCE.md)。

## 参与前请注意

本项目涉及政治制度、民主治理和人权等议题。在部分地区，参与或传播相关内容可能带来现实风险。我们尊重每个人的安全和自由选择：

- 评估你所在地区的法律和现实风险
- 使用与日常生活不同的匿名或虚拟账号
- 注意隐私保护，不公开不必要的真实身份和联系信息
- 如果存在疑虑，请不要冒险参与，也无须解释你的选择

## 结语

真实的制度不是一句口号，而是一段能被不断修正、持续讨论，并最终经得起时代检验的文本。

如果你愿意认真思考这些问题，欢迎一起把未来写得更清楚、更公平、更稳固。
