# 中华民主共和国宪法草案

> 如果未来的中国需要重新定义权力、自由与秩序，那就让我们从今天开始，认真地把这些问题说清楚。

[在线阅读](https://freedom4china.github.io/xianfa/) · [提出建议](https://github.com/freedom4china/xianfa/issues) · [参与讨论](https://github.com/freedom4china/xianfa/discussions) · [贡献指南](CONTRIBUTING.md) · [治理规则](GOVERNANCE.md)

## 这是一个什么项目？

这是一个面向未来的公开协作项目：我们试图提前思考并讨论，若未来出现一个中华民主共和国，如何在法律与制度层面保障自由、权利、法治与权力制衡。

这不是某个组织的正式宪法，也不是已经定稿的“标准答案”。它是一份可以被持续修改、讨论和完善的草案，欢迎每个人阅读、质疑、补充和重写。

我们相信，宪法不该只是少数人闭门完成的文本。它必须经得起真实社会的追问，也要能够被不同背景、不同地区、不同经历的人理解和批评。

## 为什么值得参与？

因为你的一点想法，也可能让这份草案更清晰、更公平、更有现实感。

你可以：

- 指出某条条文不够清晰，或者存在明显逻辑问题；
- 提出一个更合理、更可执行的制度设计；
- 用自己的经历说明某项权利为什么重要；
- 提供不同视角，挑战“看似合理”的规定是否真的能落地；
- 修正错字、排版、术语和结构，让文本更易读；
- 把这份草案分享给更多愿意认真思考公共事务的人。

你无需是法律专家，也不需要事先准备完整方案。只要你愿意提出一个具体问题，甚至只是一句“我不同意这里的设计”，都很有价值。

## 我们的目标

我们并不是在追求一份“完美无缺”的历史性文本，而是在构建一个开放、理性、可持续的讨论过程：

- 让权力受到约束；
- 让权利得到保障；
- 让制度更有可解释性；
- 让不同意见能够被表达和回应；
- 让公共讨论从口号走向条文、从想法走向制度。

这是一份关于未来的草案，但它也始终面向现实：怎样在现实社会中，制衡权力、保障自由、尊重多样性，并避免制度被滥用？

## 你可以怎么参与？

### 1. 提出问题或建议

在 [Issues](https://github.com/freedom4china/xianfa/issues) 中提出你的想法。你可以写：

- 某一条文本哪里不够清楚；
- 你认为某项制度可能存在漏洞；
- 你希望补充或修改哪些内容；
- 你有一个更好的替代方案。

不需要高深术语，不需要一次写成完整法律文本。只要把问题说清楚，社区会一起整理和讨论。

### 2. 参与公开讨论

前往 [Discussions](https://github.com/freedom4china/xianfa/discussions)，分享你的理由、案例或担忧。欢迎讨论冲突、对比方案、发掘现实问题。我们更重视论证与回应，而不是简单的站队。

### 3. 提交修改

如果你已经有具体修改方案，可以直接提交 Pull Request（PR）。在 PR 中说明：

- 修改了什么；
- 为什么这么改；
- 这项修改会如何影响条文逻辑、权利边界或制度设计。

如果你还不确定，可以先提 Issue，由社区协助你整理和推进。

### 4. 帮忙传播

你也可以把项目分享给朋友、社群、关注公共议题的人：

- 推荐他们读一读在线版本；
- 让他们在讨论中提出意见；
- 鼓励他们帮助修正表述或结构。

一份开放的公共文本，最需要的不是“完美”，而是被更多人认真看见、认真讨论。

## 协作方式

我们希望保持开放、理性和持续改进的协作气氛：

- 先说明问题，再回应观点；
- 以事实、理由和案例为基础；
- 允许不同意见存在，但要求它们被表达清楚；
- 把讨论落实到条文和修改中；
- 让规则透明，并按治理流程推进修订。

具体参与流程请见 [贡献指南](CONTRIBUTING.md)。重大提案的讨论和审查机制请见 [治理规则](GOVERNANCE.md)。

## 当前状态

这个项目仍在持续建设中。条文、结构、措辞和治理方式都可能随着讨论不断改进。

这也意味着：你并不需要在“所有问题都准备好”之后才来参与。只要你关心其中一处不合理、一个不明确的表述，或者一个你认为应当被加入的制度设计，你都可以先开始。

## ⚠️ 参与前请注意

本项目涉及政治制度、民主治理和人权等议题。在部分地区，参与或传播相关内容可能带来现实风险。我们重视每个人的安全和自由选择。

请在参与前：

- 评估你所在地区对相关内容的法律和现实风险；
- 使用与日常生活不同的匿名或虚拟账号；
- 注意隐私保护，不公开不必要的真实身份和联系信息；
- 如果存在疑虑，请不要冒险参与，也没有义务解释你的选择。

我们尊重每个人选择参与、旁观或退出的权利。没有任何讨论值得你牺牲自身安全。

## 让未来的制度，更值得被认真讨论

一个民主社会的基础，不只是“谁掌权”，更是“如何约束权力、保障人权，并让规则经得起所有人的追问”。

如果你也愿意认真思考这些问题，欢迎加入：

- 阅读这份草案；
- 提出你的质疑；
- 改进不清晰的表达；
- 分享给愿意一起思考未来的人。

> 真实的制度不是一句口号，而是一段能被不断修正、持续讨论、并最终经得起时代检验的文本。

如果你愿意，一起把未来写得更清楚、更公平、更稳固。
